## Ilustración de quinua

Herramienta: image_gen integrada, modo generación; sin CLI ni API key. Archivo final: public/images/quinoa-illustration.png. Revisión visual efectuada sobre el archivo guardado.

Prompt utilizado:

> Use case: product-mockup. Asset type: local product photography illustration for GastroLinkAI, a professional Peruvian B2B ingredients marketplace. Create a single photorealistic editorial product photograph of uncooked ivory white quinoa grains heaped in a small shallow handmade terracotta bowl on a warm ivory linen tabletop, a few grains scattered naturally. Quinoa grains are tiny round flat disks with a pale ring, not long rice grains. Close three-quarter overhead framing, bowl fills most of frame, elegant natural soft daylight, rich real tactile grain texture, muted earthy palette, premium culinary catalogue, square 1024x1024. No writing, no logos, no watermarks, no decorative text. This is a standalone image asset, not a website mockup.

La descarga de quinua desde Wikimedia no se incorporó: el servidor devolvió un límite de solicitudes. Se sustituyó por la imagen generada, sin atribuirle una fuente fotográfica real.

Para el MVP, reemplazar fotografías genéricas por imágenes aportadas por proveedores y registrar derechos de uso y metadatos.
